# GUIA DO GRUPO — PROJETO DE ARQUITETURA DE COMPUTADORES

## 1. Objetivo do projeto

Este repositório serve para organizar o trabalho do grupo durante o desenvolvimento de uma aplicação capaz de gerar automaticamente palavras cruzadas.

O objetivo é manter os documentos, o código, os testes e a informação do projeto organizados num único local, para que todos os membros saibam onde encontrar e colocar os ficheiros.

## 2. Funções de cada membro

### Gestor de Projeto
Responsável por organizar o trabalho do grupo, distribuir tarefas, acompanhar os prazos e garantir que todos sabem o que têm de fazer.

Principais tarefas:
- Elaborar o planeamento do projeto (GANTT e WBS).
- Acompanhar o progresso das tarefas.
- Ajudar a resolver problemas de organização e comunicação.
- Preparar os relatórios de acompanhamento e coordenar a entrega final.

### Analista / Arquiteto de Sistemas
Responsável por analisar os requisitos e organizar a estrutura e a documentação técnica do projeto.

Principais tarefas:
- Criar e organizar o repositório Git.
- Elaborar o relatório de especificação de requisitos.
- Preparar o plano de testes de aceitação.
- Criar um processo de instalação simples.
- Elaborar o manual de instalação e manutenção.
- Participar na revisão do código.

### Programador
Responsável por desenvolver a aplicação e implementar as funcionalidades necessárias.

Principais tarefas:
- Desenvolver a aplicação e as suas interfaces gráficas.
- Implementar os algoritmos de geração de palavras cruzadas.
- Desenvolver a ligação entre o cliente, o servidor e a base de dados, de acordo com a solução definida.
- Criar e executar testes unitários.
- Participar na revisão do código.

### Secretário
Responsável por manter o website do projeto e apoiar a organização da documentação.

Principais tarefas:
- Criar e manter o website do projeto.
- Registar as reuniões através de atas.
- Verificar a organização e a conformidade da documentação.
- Preparar o suporte digital com os documentos do projeto.
- Participar na elaboração do relatório científico.

## 3. Organização das pastas

- **00 - GUIA DO GRUPO:** instruções gerais, funções e regras de organização.
- **01 - Planeamento e Organização:** GANTT, WBS, atas das reuniões e distribuição de tarefas.
- **02 - Requisitos e Funcionamento:** requisitos, descrição das funcionalidades e arquitetura do sistema.
- **03 - Código da Aplicação:** código-fonte e ficheiros necessários para executar a aplicação.
- **04 - Testes e Verificação:** testes unitários, testes de aceitação e registos dos resultados.
- **05 - Relatórios e Documentação Final:** relatórios, manuais e documentos para a entrega final.
- **06 - Website do Projeto:** ficheiros e documentação relacionados com o website.

## 4. Regras de trabalho

1. Cada membro deve colocar os seus ficheiros na pasta correspondente.
2. Os ficheiros devem ter nomes claros e fáceis de compreender.
3. Antes de alterar ficheiros importantes, deve verificar-se se já existem alterações de outros membros.
4. Os documentos devem ser atualizados à medida que o projeto evolui.
5. Os prazos definidos no planeamento devem ser respeitados.
6. Em caso de dúvida, o grupo deve comunicar antes de tomar decisões que afetem o trabalho dos restantes membros.

- **17/12/2026:** segunda entrega — especificação de requisitos, testes de aceitação, primeira revisão do código e segundo relatório de acompanhamento.
