# WEBSITE DO PROJETO

## Objetivo desta pasta

Esta pasta serve para organizar os ficheiros e a documentação relacionados com o website do projeto.

O website deve apresentar o projeto e disponibilizar informação relevante sobre o seu desenvolvimento.

## O que deve ser colocado aqui?

### 1. Ficheiros do website

Ficheiros utilizados na construção do website, incluindo páginas, estilos, imagens e outros recursos necessários.

**Responsável principal:** Secretário.

### 2. Apresentação do projeto

Conteúdo que explica o objetivo do projeto, o funcionamento geral da aplicação e o trabalho desenvolvido pelo grupo.

**Responsável principal:** Secretário, com a colaboração do Analista / Arquiteto de Sistemas para garantir que a descrição técnica está correta.

### 3. Atualizações do website

Alterações necessárias para manter o website atualizado durante o desenvolvimento do projeto.

**Responsável principal:** Secretário.

### 4. Informação sobre o grupo

Informação sobre a organização do grupo, as funções dos membros e o desenvolvimento do projeto, quando necessário.

**Responsável principal:** Secretário, com a colaboração do Gestor de Projeto.

## Regras de organização

- O conteúdo deve estar atualizado e bem organizado.
- As páginas devem ser fáceis de navegar e compreender.
- A informação publicada deve corresponder ao trabalho realmente realizado.
- As alterações devem ser verificadas antes de serem publicadas.
- Não devem ser publicados dados pessoais ou informações confidenciais sem autorização.

## Resultado esperado

No final, o website deve apresentar o projeto de forma clara e organizada, cumprindo os requisitos definidos pelo professor.
