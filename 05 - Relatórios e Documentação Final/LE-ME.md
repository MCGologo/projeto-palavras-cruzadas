# RELATÓRIOS E DOCUMENTAÇÃO FINAL

## Objetivo desta pasta

Esta pasta serve para reunir e organizar os relatórios, manuais e restantes documentos necessários para acompanhar e apresentar o projeto.

Os documentos devem ser atualizados ao longo do desenvolvimento, e não apenas no final.

## O que deve ser colocado aqui?

### 1. Relatório de especificação de requisitos

Documento que descreve as funcionalidades que a aplicação deve ter e os requisitos que deve cumprir.

**Responsável principal:** Analista / Arquiteto de Sistemas.

### 2. Relatório de testes de aceitação

Documento que apresenta os testes utilizados para verificar se a aplicação cumpre os requisitos definidos e os respetivos resultados.

**Responsável principal:** Analista / Arquiteto de Sistemas, com a colaboração do Programador.

### 3. Manual de instalação e manutenção

Documento que explica como instalar, configurar, executar e manter a aplicação.

**Responsável principal:** Analista / Arquiteto de Sistemas, com a colaboração do Programador na parte técnica.

### 4. Relatório científico

Documento que apresenta o trabalho desenvolvido, a abordagem utilizada e os resultados obtidos, de acordo com as indicações do projeto.

**Responsável principal:** Secretário, com a colaboração dos restantes membros.

### 5. Relatório final

Documento que reúne a informação necessária para apresentar o projeto, o trabalho realizado e os resultados alcançados.

**Responsável principal:** Gestor de Projeto, com a colaboração de todos os membros.

### 6. Documentação complementar

Outros documentos exigidos pelo enunciado ou necessários para as entregas, incluindo documentos de acompanhamento e materiais para a apresentação final.

**Responsável principal:** Gestor de Projeto, que coordena a organização com o apoio dos restantes responsáveis.

## Regras de organização

- Os documentos devem ter nomes claros e estar atualizados.
- Sempre que possível, devem ser identificadas as versões dos documentos.
- Os relatórios devem refletir o trabalho realmente realizado.
- Antes de cada entrega, o grupo deve confirmar se todos os documentos exigidos estão preparados.
- Os documentos devem respeitar as indicações fornecidas pelo professor.

## Resultado esperado

No final, esta pasta deve reunir a documentação necessária para acompanhar, justificar e apresentar o projeto, facilitando a preparação das entregas intermédias e finais.
